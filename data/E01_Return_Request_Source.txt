CUSTOMER SERVICE POLICY — VERSION 1.0

P1. Standard returns
Customers may request a return within 30 calendar days after
delivery. The item must be unused and in its original packaging.
The request date determines whether the request is within
the return window.

P2. Proof of purchase
An order number or receipt is required.

P3. Refund amount
An approved return is refunded at the amount actually paid
for the returned item, after any discount.

P4. Refund timing
Refunds are issued to the original payment method within
5–7 business days after the returned item has been received
and inspected.

P5. Return shipping
For a change-of-mind return, the customer pays return shipping.
A free return label requires supervisor approval.

P6. Agent authority
Agents may explain the policy and request missing information.
Agents may not approve exceptions, promise an immediate refund,
or issue a free return label without supervisor approval.

P7. Incomplete information
If item condition or packaging status is unknown, request
confirmation before approving the return.
